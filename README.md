## Запуск Messenger Mini

Backend, первый терминал:

    cd messenger-mini/server
    npm install
    npm start

Frontend, второй терминал:

    cd messenger-mini/frontend
    npm install
    npm run dev

API: http://localhost:3001

Swagger: http://localhost:3001/docs
