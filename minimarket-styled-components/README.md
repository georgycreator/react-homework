# NORD Market — мини-маркет на styled-components

Учебный проект по теме «Подходы к стилизации в React». Это небольшой каталог продуктов с UI-китом, корзиной и переключаемыми темами.

## Стек

- React + TypeScript
- Vite
- styled-components 6
- Vitest + React Testing Library

## Запуск локально

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминал (обычно `http://localhost:5173`).

## Что реализовано

- Типизированная тема через `DefaultTheme` и module augmentation.
- Три цветовые схемы: светлая, тёмная и ягодная; режим «Авто» учитывает `prefers-color-scheme`.
- Выбранная тема сохраняется в `localStorage`.
- Цвета и дизайн-токены вынесены в `src/styles/theme.ts`; styled-компоненты используют значения из `theme`.
- UI-kit: `Button` (4 варианта × 3 размера, `loading`), `Badge`, `Card`, `Input`, `Grid`.
- Пользовательский интерфейс, подписи, описания товаров и демонстрационные примеры локализованы на русский язык; английскими остаются только названия технологий, API и бренд NORD Market.
- Полиморфный `Button` поддерживает `as="a"`: для переходов используется тот же визуальный компонент, но в DOM рендерится семантическая ссылка. Для ссылок в состоянии `disabled`/`loading` переход блокируется, выставляются `aria-disabled` и `tabIndex=-1`.
- `Input` использует `.attrs()` для поискового поля: `type="search"` и `autoComplete="off"` задаются как значения по умолчанию, но `autoComplete` можно переопределить снаружи.
- Для style-only props используются transient props с префиксом `$`.
- Используются инструменты из лекции: `styled(X)` для расширения `Card`, `css` для условного фрагмента `Button`, `as` для кнопки-ссылки, `.attrs()` для поискового поля, `createGlobalStyle` для общих правил и `keyframes` для анимаций.
- Глобальные стили оформлены через `createGlobalStyle`, а анимации — через `keyframes`.
- Каталог поддерживает поиск, фильтрацию категорий, добавление товара в корзину с состоянием загрузки, адаптивную сетку и пустое состояние.
- Корзина объединяет повторные добавления одного товара, считает количество единиц и общую сумму, позволяет увеличить/уменьшить количество и удаляет позицию при уменьшении до нуля.
- Содержимое корзины сохраняется отдельно от темы в `localStorage`; при восстановлении игнорируются некорректные записи и товары, которых больше нет в каталоге. Если хранилище недоступно, приложение продолжает работать в рамках текущей сессии.
- Корзина демонстрационная: серверного оформления заказа и оплаты нет; сохранение работает в браузере пользователя.
- Корзина закрывается клавишей `Escape` и кликом вне поповера; при открытии фокус переводится на кнопку закрытия, при закрытии с клавиатуры возвращается на кнопку корзины.
- Дополнительно: тесты на полный сценарий корзины и восстановление из хранилища, skeleton loading, skip-link, focus-visible и поддержка `prefers-reduced-motion`.

## styled-components против CSS Modules на моём проекте

В этом проекте styled-components оказался удобен тем, что стили компонента находятся рядом с его логикой и типами. Варианты кнопки, размеры и состояния описаны один раз и выбираются через типизированные пропсы, поэтому не приходится собирать длинные строки классов. Тема доступна непосредственно внутри styled-компонентов, а TypeScript проверяет структуру `DefaultTheme` и помогает не ошибиться в названиях токенов. Для CSS Modules пришлось бы хранить стили отдельно, а динамические варианты переключать через классы и дополнительные условия в JSX. При этом CSS Modules не добавлял бы runtime-работу для вычисления стилей, поэтому мог бы быть выгоднее в интерфейсе с большим количеством статичных компонентов. Для небольшого тематического UI-кита styled-components оказался нагляднее, хотя его runtime и тесная связь оформления с React — компромисс, который важно учитывать в более крупном приложении.

## Структура проекта

```text
src/
├── components/
│   ├── catalog/       # каталог, карточка товара, skeleton и тесты
│   ├── layout/        # шапка, корзина, переключатель темы, showcase
│   └── ui/            # Button, Badge, Card, Input, Grid
├── context/           # ThemeProvider и его тесты
├── data/              # каталог, типы корзины и проверка localStorage
├── styles/            # темы, DefaultTheme, GlobalStyle, keyframes
└── test/              # настройка тестовой среды
```
