# NORD Market — мини-маркет на styled-components

Учебный проект по теме «Подходы к стилизации в React». NORD Market — небольшой интернет-магазин продуктов с собственным UI-китом, адаптивным каталогом, корзиной и переключаемыми темами оформления.

## Технологический стек

- React
- TypeScript
- Vite
- styled-components 6
- Vitest
- React Testing Library

## Запуск проекта

Для работы необходим установленный Node.js и npm.

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/georgycreator/react-homework.git
cd react-homework/minimarket-styled-components
```

Установите зависимости:

```bash
npm install
```

Запустите локальный сервер разработки:

```bash
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминале (обычно http://localhost:5173).

## Проверка проекта

Проверка типов TypeScript:

## Реализованные возможности

### Темизация

- Типизированная тема через `DefaultTheme` и module augmentation.
- Три цветовые схемы: светлая, тёмная и ягодная.
- Режим «Авто», учитывающий системную настройку `prefers-color-scheme`.
- Сохранение выбранной темы в `localStorage`.
- Централизованные цветовые и дизайн-токены в `src/styles/theme.ts`.
- Отсутствие захардкоженных цветов в стилях компонентов: оформление зависит от значений активной темы.

### UI-kit

Реализованы переиспользуемые компоненты:

- `Button` — 4 варианта оформления, 3 размера и состояние `loading`.
- `Badge` — информационные значки.
- `Card` — базовая карточка.
- `Input` — поле ввода с поддержкой состояний.
- `Grid` — адаптивная сетка.

В демонстрационном разделе UI-kit представлены варианты компонентов и их состояния.

Пользовательский интерфейс, подписи, описания товаров и демонстрационные примеры локализованы на русский язык. Английскими остаются названия технологий, программных интерфейсов и бренд NORD Market.

### Приёмы styled-components из лекции

- Для style-only props используются transient props с префиксом `$`.
- `styled(X)` применяется для расширения существующего компонента `Card`.
- `css` используется для создания условных CSS-фрагментов.
- Полиморфный `Button` поддерживает `as="a"` и позволяет использовать оформление кнопки для семантических ссылок.
- Для ссылок в состояниях `disabled` и `loading` предусмотрена блокировка перехода, а также атрибуты `aria-disabled` и `tabIndex`.
- `Input` использует `.attrs()` для назначения стандартных атрибутов поисковому полю: `type="search"` и `autoComplete="off"`. Значение `autoComplete` можно переопределить.
- `createGlobalStyle` применяется для глобальных стилей.
- `keyframes` используется для анимаций загрузки и декоративных элементов.

### Каталог товаров

- Поиск товаров по названию.
- Фильтрация по категориям.
- Добавление товаров в корзину с отображением состояния загрузки.
- Адаптивная сетка с 1, 2, 3 или 4 колонками.
- Пустое состояние при отсутствии результатов.
- Skeleton loading во время первоначальной загрузки.
- Цены и описания товаров вынесены в отдельный каталог данных.

### Корзина

- Добавление нескольких товаров.
- Объединение повторных добавлений одного товара в одну позицию.
- Изменение количества товаров кнопками увеличения и уменьшения.
- Автоматический пересчёт стоимости каждой позиции и общей суммы.
- Удаление позиции при уменьшении количества до нуля.
- Сохранение содержимого корзины в `localStorage`.
- Восстановление корзины после обновления страницы.
- Игнорирование некорректных записей и товаров, отсутствующих в актуальном каталоге.
- Работа в рамках текущей сессии при недоступности `localStorage`.

Корзина является демонстрационной: серверного оформления заказа и оплаты нет. Данные сохраняются только в браузере пользователя.

### Доступность

- Семантическая разметка.
- Поддержка клавиатурной навигации.
- Видимые индикаторы фокуса через `:focus-visible`.
- Skip-link для быстрого перехода к основному содержимому.
- Закрытие корзины клавишей `Escape` и кликом вне неё.
- Управление фокусом при открытии и закрытии корзины.
- Поддержка `prefers-reduced-motion`.

## styled-components против CSS Modules на моём проекте

В этом проекте styled-components оказался удобен тем, что стили компонента находятся рядом с его логикой и типами. Варианты кнопки, размеры и состояния описаны один раз и выбираются через типизированные пропсы, поэтому не приходится собирать длинные строки классов. Тема доступна непосредственно внутри styled-компонентов, а TypeScript проверяет структуру `DefaultTheme` и помогает не ошибиться в названиях токенов. Для CSS Modules пришлось бы хранить стили отдельно, а динамические варианты переключать через классы и дополнительные условия в JSX. При этом CSS Modules не добавлял бы runtime-работу для вычисления стилей, поэтому мог бы быть выгоднее в интерфейсе с большим количеством статичных компонентов. Для небольшого тематического UI-кита styled-components оказался нагляднее, хотя его runtime и тесная связь оформления с React — компромисс, который важно учитывать в более крупном приложении.

## Структура проекта

```text
src/
├── components/
│   ├── catalog/       # каталог, карточка товара, skeleton и тесты
│   ├── layout/        # шапка, корзина, переключатель темы, UI-kit
│   └── ui/            # Button, Badge, Card, Input, Grid
├── context/           # ThemeProvider и его тесты
├── data/              # каталог товаров, корзина и localStorage
├── styles/            # темы, DefaultTheme, GlobalStyle, keyframes
└── test/              # настройка тестовой среды
```
