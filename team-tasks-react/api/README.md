# Локальный API команды и задач

Express API для учебного проекта из семинара «SPA, Redux Toolkit и RTK Query».

## Запуск

Требуется Node.js 22.12 или новее.

```bash
npm ci
npm start
```

По умолчанию API доступен только на `http://127.0.0.1:3001`. Параметры можно изменить через окружение:

- `HOST` — адрес прослушивания; по умолчанию `127.0.0.1`;
- `PORT` — порт; по умолчанию `3001`;
- `DATA_FILE` — путь к JSON-файлу базы;
- `CORS_ORIGINS` — список разрешённых origin через запятую. По умолчанию разрешены `localhost` и `127.0.0.1` для портов Vite `5173` и preview `4173`.

Не выставляйте API в публичную сеть: в учебной версии нет аутентификации и авторизации.

## Маршруты

| Метод и путь | Результат |
| --- | --- |
| `GET /users` | `200`, массив участников с `id`, `name`, `email` |
| `GET /tasks?userId=1&status=todo` | `200`, список задач; `userId` обязателен, `status` необязателен |
| `GET /tasks/:id` | `200`, объект задачи |
| `POST /tasks` | `201`, созданная задача и заголовок `Location` |
| `PATCH /tasks/:id` | `200`, обновлённая задача |
| `DELETE /tasks/:id` | `204`, пустой ответ |

Все ID — строки. Статусы: `todo`, `doing`, `done`. Название задачи после обрезки пробелов должно содержать от 1 до 120 символов. `POST` принимает только `userId`, `title`, `status`; `PATCH` — только `title` и/или `status`.

## Защитные проверки

- Разрешены только origin из `CORS_ORIGINS`; запросы без `Origin` (например, локальные CLI-команды) разрешены.
- Максимальный размер JSON — 16 КБ.
- Проверяются типы данных, уникальность ID, существование пользователя, статус и длина названия.
- Добавлены заголовки `nosniff`, `DENY` для iframe и `no-referrer`.
- Файл обновляется через временную запись и атомарное переименование. Повреждённый файл не заменяется автоматически seed-данными.
- По умолчанию сервер слушает только loopback-интерфейс.

## Данные

При первом старте `data/db.json` создаётся из `src/seed.json` (4 участника, 8 задач). Изменения задач переживают перезапуск. Файл данных не включается в Git. Один файл базы рассчитан на один процесс API.

## Тесты

```bash
npm test
```

Используется встроенный `node:test`, отдельный тестовый сервер и временная база. Проверяются CRUD, фильтрация, валидация, CORS, размер запроса, параллельное создание, сохранение после рестарта и реакция на повреждённый JSON.
